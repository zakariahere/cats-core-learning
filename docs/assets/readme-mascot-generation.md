# Public repository README illustration

Created for the public Cats Core learning lab with the built-in image-generation
tool and the `zakaria-mascot` skill. Project asset: `cats-core-readme.png`.

The approved reference images were inspected before generation:

- `zakaria-mascot/assets/mascot-source.png`: canonical facial identity, navy hood,
  orange drawstring tips, outfit, and compact proportions.
- `zakaria-mascot/assets/single-scene-reference.png`: polished manga-comic rendering,
  ink, halftone texture, and color treatment.

The references are identity/style inputs and are not distributed in this repository.

## Generation prompt

Create one new polished ultra-wide landscape 2.4:1 manga-comic illustration for the opening banner of Zakaria's public Cats Core Scala learning repository. Use reference 1 strictly for mascot identity: recognizable face, expressive dark eyebrows, short dark beard, deep navy hoodie with hood up, orange drawstring tips, compact stylized proportions, dark trousers, black sneakers. Use reference 2 strictly for established richly polished modern manga-comic rendering: crisp expressive black ink, halftone and screentone, dimensional warm skin, deep navy fabric, selective vivid orange accents, cinematic light. Scene: a friendly outdoor learning expedition in a beautiful sunlit mountain valley, the smiling mascot crouches at the near end of a short footbridge, placing the final glowing orange interlocking wooden block between two connected groups of blue blocks to complete the crossing. One small ginger cat sits beside him, watching. The bridge across a tiny clear stream and a winding path up toward distant hills suggest learning one step at a time. Composition must be wide and clean, hero mascot large enough to recognize on the left third, the simple bridge and cat in center, bright inviting mountain panorama on right. Warm sunrise colors with navy and orange accents, confident shapes and premium editorial comic art. This is a symbolic illustration, not a technical diagram. No lettering, no code, no logos, no watermarks, no other people, no repeated mascot. Reference backgrounds, props, poses and their room are not requirements. Preserve canonical identity, outfit, apparent age, and rendering.
